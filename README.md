# Pax Silica | Team Portfolio

A multi-page portfolio website for the Pax Silica team, built with pure HTML and CSS (no JavaScript).

## Pages
- `index.html` Home
- `about.html` About the group
- `team.html` Team members
- `projects.html` Projects
- `skills.html` Skills and tools
- `contact.html` Contact

## Run locally
Open `index.html` in any browser. No build step needed.

## Deploy on GitHub Pages
1. Create a new repository and upload all files in this folder.
2. Go to Settings > Pages.
3. Set Source to "Deploy from a branch", choose `main` and `/ (root)`, then Save.
4. Your site will be live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Easy edits
- Colors and fonts: top of `css/style.css` (`:root` variables).
- Team info: `team.html`.
- Projects: `projects.html`.
- Contact details and GitHub links: `contact.html` and the footer of each page.
- Logo: replace `assets/logo.png` and `assets/favicon.png`.
